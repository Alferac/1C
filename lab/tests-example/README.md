# Пример автотеста к модулю 06 (YAxUnit)

Тест проверяет задания **M06-T3 / M06-T4**: документ `РеализацияТоваров` не проводится при нехватке остатка, а при достаточном остатке формирует корректные движения по `ОстаткиТоваров`.

Как подключить:

1. Установите расширение YAxUnit (`YAXUNIT-*.cfe` из релизов github.com/bia-technologies/yaxunit): Конфигуратор → *Конфигурация → Расширения конфигурации → Добавить → Загрузить из файла*. **Снимите флаги «Безопасный режим» и «Защита от опасных действий»** у расширения.
2. Создайте своё расширение `Tests` (*Добавить → Новое*, назначение — «Дополнение»), снимите те же флаги.
3. Добавьте в `Tests` общий модуль `ОМ_М06_КонтрольОстатков` (флаги: *Сервер*, *Клиент (управляемое приложение)*, *Вызов сервера* — **нет**), вставьте код из [`ОМ_М06_КонтрольОстатков.bsl`](ОМ_М06_КонтрольОстатков.bsl).
4. Запуск: `scripts/check.sh ОМ_М06_КонтрольОстатков` или из режима 1С:Предприятие через меню YAxUnit.

Соглашение курса: один модуль тестов на модуль курса — `ОМ_МNN_<Тема>`. Тесты — серверные, в транзакции (`ВТранзакции()`), поэтому база после прогона не засоряется.
