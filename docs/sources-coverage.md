> **Главное ограничение источников.** Все пять файлов — **программы (перечни тем)**. Учебного содержания (теории, примеров кода, заданий, баз-примеров) в них нет ни по одной теме. Поэтому все тексты, схемы, код и задания курса написаны заново по документации платформы 8.3 и практике разработки. Источники задали состав тем, их порядок и объём.
>
> [К] полностью включает [ПР] и [ПР2] (модули 1–17 [К] дословно совпадают с ними), поэтому уникальный вклад [К] — только модуль 18.

## Темы, которых НЕТ в предоставленных материалах

Ниже — темы курса, которые не упоминаются ни в одной из пяти программ, даже заголовком. Их состав и содержание определены мной: они нужны ABAP-разработчику для реальной работы или для локального стенда. Списки по модулям собраны авторами модулей; в каждом модуле они продублированы в шапке («Нет в источниках»).

### Сквозные (касаются всего курса)

* **Сопоставление SAP ↔ 1С.** Ни одна программа не рассчитана на переход из другой ERP-платформы. Все карты понятий, «ловушки для ABAP-разработчика» и параллельные примеры ABAP ↔ 1С написаны с нуля.
* **Интеграция 1С ↔ SAP** (OData/REST, SOAP, файлы, 1С:Шина) — модуль 11.
* **Локальный стенд:** комьюнити-лицензия разработчика (8.3.23+), Docker (СУБД, сборка образов onec-docker), скрипты сборки ИБ из исходников, автоматическая проверка заданий через YAxUnit — [lab/](../lab/README.md). В источниках есть только «учебная версия платформы», «облачный тренажёр edu.1cfresh.com», установка MS SQL и создание серверной базы.
* **EDT + git как основной процесс разработки.** В источниках есть «хранилище конфигурации» и «групповая разработка», git упоминается только в контексте 1С:Элемент.
* **Модульное тестирование (YAxUnit), статический анализ (АПК, SonarQube + BSL Language Server), CI** — модуль 14. В источниках из тестирования есть только Vanessa-Automation.
* **Технологический журнал, ЦУП, APDEX** — модуль 12. В источниках есть только «замер производительности» и «основные причины неоптимальной работы запросов».
