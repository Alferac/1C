# Что сверить с документацией платформы

Код 1С в курсе написан без запуска: при подготовке не было доступа к платформе. Схемы Mermaid проверены парсером (mermaid 11.4), ссылки между файлами проверены скриптом. API YAxUnit в `lab/tests-example` сверен с официальной документацией проекта.

Ниже — утверждения, в которых авторы модулей не были уверены на 100 %. Первое прохождение курса — хороший повод их проверить: ученик сверяет пункт в синтакс-помощнике или на its.1c.ru/db/v83doc, ставит галочку, а при расхождении правит модуль.

## Проверено при сборке курса

| Утверждение | Статус |
|---|---|
| Метода `ВыбратьРекурсивно` у результата запроса нет, рекурсивный обход делается вложенным `Выбрать(ОбходРезультатаЗапроса.ПоГруппировкамСИерархией)` | так и написано в модуле 04 |
| `ПриЧтенииНаСервере` вызывается раньше `ПриСозданииНаСервере` у формы объекта | верно |
| Режим округления по умолчанию у `Окр` — `Окр15как20` | верно |
| `ФоновыеЗадания.ОжидатьЗавершенияВыполнения` (с 8.3.13) заменяет устаревший `ОжидатьЗавершения` | верно |
| Порядок применения расширений по назначению: Исправление → Адаптация → Дополнение | верно |
| YAxUnit: `ЮТТесты.ДобавитьТест`, `ДобавитьСерверныйТест`, `ВТранзакции`, `УдалениеТестовыхДанных`, `ЮТест.ОжидаетЧто(...).Равно/ЭтоЛожь`, `ЮТест.Данные().КонструкторОбъекта(...)`, ключи `RunUnitTests`, `exitCode` | сверено с документацией YAxUnit |
| Одно- и многокомпонентные мобильные приложения ([ПР] модуль 6) | определение не подтверждено, в модуле 90 стоит пометка «сверить на ИТС» |
| vanessa-runner: в модуле 14 команды версии 2.x, в 3.0 они переименованы | пометка добавлена в модуль 14 |
